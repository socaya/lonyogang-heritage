# LonyoGang Heritage — Flutter / Dart

A private, owner-controlled **personal wealth and asset portfolio tracker** for Uganda, styled with the approved Theme 1 design (Midnight Navy, Antique Gold and Sage). **HERITAGE** appears directly below **GANG**, and the Acholi-inspired granary identity is retained. Android and iOS share one Flutter codebase.

## Status and privacy (read first)

This is a **functional offline-first alpha**, not a complete production-ready financial product. It implements native Flutter UI and persisted local workflows for financial assets, savings, property, liabilities, transaction logs, goals, trusted contacts, reminders and net-worth reports. It **does not** provide authenticated accounts, encrypted financial storage, remote sync, payments, licensed investment advice, bank feeds, verified valuations, actual passkey registration, scheduled device notifications or legal beneficiary transfers. Do not enter genuine financial or identity data; current local storage uses `shared_preferences` and an optional plain JSON export.

## Supported workflows

- Owner-named portfolio setup with an explicit 390M/70M sample portfolio from the SRS (optional, never silently preloaded).
- Dashboard, portfolio filters, asset detail, add/edit/archive investments, savings, properties and other assets.
- Property ownership share in basis points, valuation source and as-of date; property equity with linked mortgages.
- Add/edit/archive liabilities, including property-linked loans; consolidated net worth subtracts liabilities **once**.
- Append-only transaction log (contribution, withdrawal, interest, dividend, rent, expense, fee, tax, transfer, adjustment) with auditable reversal events. Financial events do not silently change asset valuations.
- Goals, in-app reminders, trusted contacts, asset composition, signed financial statement, external contributions and realized income summaries.
- Local JSON import/export with explicit unencrypted-export disclosure.

## Run

Install the [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable), Android SDK and/or Xcode.

```sh
flutter create --platforms=android,ios --org com.lonyogang .
flutter pub get
flutter analyze
flutter test
flutter run
```

Native platform wrappers are generated by `flutter create` because this delivery environment has no Flutter SDK. The GitHub CI workflow generates them and builds a debug APK. An iOS build requires macOS + Xcode.

## Code organization

- `lib/domain` — typed asset, mortgage, ledger, goal, trusted contact and reminder models; integer-UGX accounting.
- `lib/data` — persistent local repository, import/export and explicit sample dataset.
- `lib/core` — theme tokens and money formatting.
- `lib/presentation` — reusable widgets, responsive pages and interactive forms.
- `test` — financial fixture and serialization tests.
- `assets/reference/screens` — source PNGs; used for visual comparison, not as rendered app screens.
- `docs` — architecture, implementation scope and visual review checklist.

## Verification

Run `flutter analyze` and `flutter test` locally or use GitHub Actions. CI also builds an Android debug APK. Passing checks verify compilation and domain tests, **not** exact pixel matching to reference images or production security readiness.


## Flutter 0.4.0 scope

The implementation includes fully navigable Flutter widget screens for: financial position, holdings, global portfolio search, date-filtered cash flow, property rental income, historical valuations and valuation capture, archived-record restoration, document metadata registration **with real encrypted-at-rest attachments**, beneficiary intentions, notification center and preferences, on-device portfolio profile, security status, billing information, in-app help, About, **passphrase/biometric unlock, target allocation & drift, scheduled contributions, and offline FX reference rates.**

Use the **More** tab to explore these workflows. Reports and asset details also link to contextual analysis pages. The 6.7-inch UI reference images are under assets/reference/screens, and native Flutter preview exports are published by GitHub Actions under the lonyogang-ui-previews-1080x2400 artifact.

0.4.0 makes the local data path real: a passphrase derives an AES-GCM 256 key under PBKDF2-HMAC-SHA-256 (120k iterations), document attachments are encrypted on device, and reminders/document expiries/scheduled contributions schedule real OS notifications via `flutter_local_notifications`. See `docs/REMAINING_SCREENS.md` for a screen-by-screen map and `docs/SECURITY.md` for the on-device security boundary.

## Online services (backend)

A full Node 20 + TypeScript + Fastify + Postgres backend lives in `backend/`. It implements identity (passkey + password + TOTP + Shamir recovery), zero-knowledge event-sourced sync with Merkle hashes, S3-presigned attachment relay, FX feed with provider adapters (exchangerate.host, Bank of Uganda, mock), Flutterwave + Stripe webhook receivers, FCM + APNs push, and a Merkle-chained audit log — see `backend/README.md` for the full feature list and `docs/ONLINE_SERVICE_PLAN.md` for the design plan.
