# Architecture — local-first Flutter MVP

```
Flutter Material3 screens
    |
    v
WealthStore (ChangeNotifier)
    |
    v
VaultRepository
    |-- flutter_secure_storage -> hardware-protected OS keychain/keystore
    |-- local_auth -> device biometric access check
    |-- sqflite_sqlcipher -> device-local encrypted SQLCipher records
    |
    +-- Assets + valuation journal
    +-- Liabilities + linked property mortgages
    +-- Transactions + cash flow
    +-- Beneficiaries + reminders
    +-- Document metadata + encrypted binary content

Pure Dart domain:
  Money (integer UGX)
  Owned asset value = full value * ownership BPS / 10000
  Net worth = sum(owned asset values) - sum(outstanding liabilities)
  Property equity = owned property value - linked mortgage/debt balance
  Cash flow = recorded income minus expenses
```

### Important invariants

1. A mortgage is **not** embedded as a negative property asset and subtracted a second time.
2. A contributor's payment record is not automatically treated as a new asset valuation; balances and flows are separate.
3. Co-owned properties contribute only a user's economic ownership share to net worth.
4. Snapshot value must have a source and date; stale indicators depend on asset class.
5. User-generated files are stored as SQLCipher-encrypted blobs; decrypted exports require explicit confirmation.
6. A beneficiary/contact record does not create a legal inheritance or nomination right.
7. No demo holdings are silently populated into a new user vault.

### Offline constraints

Everything above works without a network after installation. Cross-device sync, independent recovery and remote banking integrations require a security-reviewed backend and are **not** in the current release. The app is an operational offline portfolio MVP, not a completed consumer production SaaS.

### Build and CI

Flutter SDK 3.47+, Dart 3.10+, `flutter pub get`, `flutter analyze`, `flutter test`, `flutter build apk --debug`. The platform host project is generated by `tool/setup_platform.sh`. Release code signing is a separate operation.
