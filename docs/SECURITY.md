# Security boundary for the prototype

This source package intentionally has no credentials, live client records, password store, financial account API token, payment processing, raw confidential SRS attachment or unencrypted persistent wealth storage. Sample names and balances are illustrative. The verification and passkey interfaces do **not** constitute actual authentication.

Do not deploy for handling real consumer asset records until secrets management, server authorization, data encryption, passkey/OTP integration, secure recovery, exports, auditability, privacy/legal review, and independent security testing have been completed.
