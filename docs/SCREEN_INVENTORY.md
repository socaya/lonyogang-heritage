# Screens and workflows

| User journey | Implementation |
|---|---|
| Onboarding / demo selection | `WelcomeScreen` |
| Home / net worth | `HomeScreen` |
| Portfolio category filtering | `PortfolioScreen` |
| Investments, savings, other asset creation | `AssetForm` |
| Property creation and ownership (%) | `AssetForm` |
| Asset detail / edit / archive | `AssetDetails` |
| Mortgage or other debt create/edit/archive | `LiabilityForm`, `DebtsScreen` |
| Transactions / reversal | `EventForm`, `TransactionsScreen` |
| Net worth / gross assets / income report | `ReportsScreen` |
| Goals | `GoalsScreen` |
| Heritage / trusted contacts | `LegacyScreen` |
| Reminders / completion | `RemindersScreen` |
| JSON export/import and demo data | `SettingsScreen` |

Approved visual PNGs live in `assets/reference/screens`. They are visual acceptance references and are not displayed as faux app UIs.
